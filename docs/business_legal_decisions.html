The three that are urgent, and why each is

Different reasons. Two are gates; one prevents an error that would not announce itself.
LEG-1 · LEG-7

These two gate the other six, and there is a deadline that is not ours

Gates
Why now
Impellam Group and HeadFirst Group unify under a new brand in the coming weeks. The model was built so that a rebrand costs one new company row, two ownership rows and two dates — no key changes, no reload, and every historical figure still rolls up the way it did when it was recorded.
The catch
That only holds if the register exists before the rebrand. Built afterwards, the same change means reconstructing which company owned what on which date, from feeds that only ever carried a display name.
Not lookups
Both are choices with consequences that are expensive to reverse. LEG-1's value is hashed into every key touching a legal entity — changing it later is not an edit, it is a re-key of the whole family. LEG-7 is about ownership: a spreadsheet answered once decays from the day it is filled in.
What we need
One sentence naming the identifier, and a named owner with a location a job can read.
WDJ-10

One sentence from finance, and it prevents a silent error

Silent if wrong
The question
Workday is one global tenant; our data platform is four regional lakes. Is C6130 Engineering one cost centre that four regions charge to, or four regional engineering functions sharing a code?
Why it matters
Our keys are derived from business values. If the meaning is global, we key on the code and one cost centre is one row everywhere. If the meaning is regional and we key on the code alone, two different cost centres silently become one row — nothing fails, no gate reddens, and the numbers are simply wrong at every level above.
We have met this before
It is the same shape as the buyer column in our VMS feeds, which carried three different things under one name and read as one. That took a fortnight to model out, and it was found by accident.
What we need
A cost centre means the same thing group-wide, or it does not. If it does not, what scopes it — company, region, something else — and we will key on the pair. Both answers are workable. Only silence is not.
