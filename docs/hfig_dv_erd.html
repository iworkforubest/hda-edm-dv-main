Masked columns

Masks are declared per column in metadata and emitted into each table's definition — for streaming tables and materialized views, an ALTER TABLE … SET MASK would not survive a pipeline update. The pipeline run-as identity must be privileged under every mask, or a refresh materialises NULLs into the vault.
